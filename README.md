# LIRA-Project
Communication routing project for the game Oxygen Not Included. Objective is to have an automated system that requests and sends supply payloads by sending and interpreting data through data bits.

In the game Oxygen Not Included, you control characters, known as dupes, to set out across your starting planetoid to create a self-sustaining colony using the resources on your starting planetoid, or from nearby planetoids after establishing a rocket program. While the majority of the game is player-led, there are various tasks that are better automated, both recovering time from the dupes and yourself as the player do spend elsewhere. Automated systems often range from turning on a water pump when below or above a water level to calculating the harvest and automating the harvest of arbor trees to turn into ethanol. 

When colonizing other planetoids, the player will often need resources sent from the home planetoids--steel, plastics, iron, food, you name it. While it isn't necessary to build full-fledged colonies on every planetoid, I had set out for it in my game to build outposts and collect the resources from them which sometimes required external resources that the planetoid didn't have, such as water, oil, steel, or if there was a crew there, food, or other industrial supplies. Since this is an often tedious task to manage across several planetoids, I set out to create a system that would automate requests and deliveries requiring minimal intervention, creating LIRA, or the League Interplanetary Routing Array, with "League" referring to the name of my cluster of planetoids, "The Circuit League" respectively.
